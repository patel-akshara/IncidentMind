# 3-Minute Demo Script

## 0:00–0:25
“Hi, I’m Akshara. I built IncidentMind, an incident-response agent that remembers production failures instead of treating every incident as a brand-new problem.”

## 0:25–0:50
Enter the checkout latency incident and click **Analyze without memory**.

“The model only has the current symptoms.”

## 0:50–1:20
Click **Analyze with Hindsight** using the exact same incident.

“Now the agent retrieves relevant incidents from its memory bank.”

Show the memory panel.

## 1:20–2:15
Explain one recalled incident and compare the analysis.

“The historical incident does not prove the current root cause. It changes the investigation order by providing evidence about similar failures and fixes.”

## 2:15–2:40
Enter the root cause and resolution and click **Save incident to memory**.

“That postmortem is now another memory available to future investigations.”

## 2:40–3:00
“The key idea is not that the model knows everything. It is that the agent accumulates organizational experience and can use it when a familiar failure appears again.”
